# 미사일 테트리스

블록을 쌓다 보면 ◆ 와 ★ 가 섞여 나옵니다. 그 칸이 든 줄을 지우면 미사일이 한 발씩 쌓이고,
아래로 쏴서 막힌 자리를 뚫습니다.

- 🚀 **일반 미사일** (◆) — 한 줄기로 내려가며 맞은 블록 하나를 부숩니다.
- 💥 **대형 미사일** (★) — 천천히 내려가다 반경 두 칸을 통째로 날립니다.

줄이 지워질 때는 블록이 한 칸씩 차례로 바스러져 아래로 흘러내립니다.

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | ← → | 화면 아래 ◀ ▶ · 판 위에서 좌우 스와이프 |
| 회전 | ↑ | ⟳ · 판을 짧게 탭 |
| 빠르게 내리기 | ↓ | ▼ · 아래로 살짝 스와이프 |
| 즉시 낙하 | Space | ⤓ · 아래로 길게 스와이프 |
| 미사일 | F / G | 🚀 / 💥 |
| 소리 | M | 🔊 버튼 |

효과음과 배경음은 파일 없이 브라우저가 직접 만들어 냅니다 — 이 저장소는 HTML 한 장이 전부입니다.
